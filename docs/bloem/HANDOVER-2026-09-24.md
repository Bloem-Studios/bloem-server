# Handover — 2026-09-24

Where the Silo sync, the 20-item fix program and the seam-extraction round
stand, so work can resume on another machine without any local state.

## Standing goals

- **Silo is correct.** Bloem sits on top of Silo with the smallest possible
  footprint in Silo-owned files (files that exist in `upstream/main`). Every
  edited Silo line is a merge conflict on every sync, and Silo moves fast.
- New Bloem code goes in Bloem-owned files: `bloem_*.go` in the same package,
  Bloem packages, `web/src/**/bloem*` modules, `docs/bloem/**`. A Silo file
  should carry at most a hook line: a nil-checked call, a setter-injected
  function or interface, or one embedded Bloem struct.
- `contracts/seams.txt` lists every Silo-owned file Bloem changes. Its count
  only goes down. `make verify-seams` enforces it.
- No PRs to Silo for now (ruled 2026-09-23: "those wait").

## How to validate

```sh
make embed-stub
export GOWORK=off SILO_TEST_DATABASE_URL=postgres://…/bloem_test?sslmode=disable
export SILO_SCENARIO_DATABASE_URL=postgres://…/bloem_scn_ci?sslmode=disable
TEST_DB_RECREATE=1 make test-db-prepare
go build ./... && go vet ./...
for t in $(grep -o '^verify-[a-z0-9-]*:' Makefile | tr -d :); do make "$t" || echo "FAIL $t"; done
BASE_SHA=<last pushed sha> scripts/bloem-lint-changed-ci.sh
make test-go test-scenarios test-web
```

Run `verify-offline-routes` without `SILO_TEST_DATABASE_URL`, or after the DB
is prepared. Use a Postgres container with `--shm-size=1g`; the 64 MB default
crashes under the suite. On a loaded machine, web tests time out en masse, so
rerun with `--testTimeout=60000` before believing a failure.

## Syncing Silo

1. `git fetch upstream`, then `git merge --no-ff --no-commit upstream/main`.
2. After resolving, diff `.github/workflows/ci.yml` against upstream's and check
   every job's service and env. Git auto-merges upstream jobs around Bloem's.
3. Regenerate: `route-inventory`, `migration-ledger`, `apiv2-openapi`,
   `apiv2-fixtures`, `apiv2-web-types`, `client-dtos`, `client-digest`,
   `settings-bindings`, `playback-fixtures`.
4. Check that no upstream change was dropped: for each Silo file upstream
   changed that Bloem still diverges on, upstream's added lines must be present
   and its removed lines gone.
5. Remove `seams.txt` entries for files that became identical to Silo.
