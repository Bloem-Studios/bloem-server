# Stream map images

`earth-blue-marble.jpg` is the stream globe's Earth: NASA Blue Marble imagery, the same file Proxy Manager's
web Globe and the Bloem Globe libraries ship (2048 × 1024, JPEG quality 90, about 432 KiB).

- NASA collection: https://visibleearth.nasa.gov/collection/1484/blue-marble
- Image use: https://www.nasa.gov/nasa-brand-center/images-and-media/

NASA imagery is public domain. NASA asks for credit, so the globe shows "NASA Blue Marble", linked to the
collection. NASA does not endorse Bloem.

The flat map's tiles (Esri World Dark Gray and Light Gray Base) and the satellite imagery (Esri World Imagery)
load from Esri's ArcGIS Online services without a key, under Esri's terms of use. The widgets show the credit
those terms ask for: "Powered by Esri" on the map, and the imagery providers on the satellite view.
